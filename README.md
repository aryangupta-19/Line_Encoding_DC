# Digital Signal Encoding and Decoding

## Features
- Random binary sequence generation.
- Binary sequences containing 4 or 8 consecutive zeros.
- Finding the longest palindromic substring.
- Line encoding: NRZ-L, NRZ-I, Manchester, Differential Manchester, and AMI.
- Decoding of line-coded signals.
- B8ZS and HDB3 scrambling and descrambling.
- Delta Modulation encoding and decoding.
- Signal waveform visualization using Matplotlib.

## Requirements
- Python 3
- Matplotlib
